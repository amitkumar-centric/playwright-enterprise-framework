Locator Strategy

1. Prefer data-testid for application-controlled elements.
2. Prefer accessible roles/labels for user-facing controls.
3. Avoid CSS classes tied to styling.
4. Avoid nth-child selectors.
5. XPath only as last resort.
6. Keep locators inside Page Objects.
7. Locator names must describe business meaning.
8. Never duplicate the same locator across multiple tests.
